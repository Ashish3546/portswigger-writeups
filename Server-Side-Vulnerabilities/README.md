# Server-Side Vulnerabilities 🖥️

This section contains my detailed write-ups and hands-on solutions for
server-side vulnerability labs from the **PortSwigger Web Security Academy**.

Each write-up focuses on understanding the underlying vulnerability,
identifying the vulnerable functionality, analyzing HTTP requests and
responses using Burp Suite, reproducing the vulnerability, and documenting
the security impact and relevant mitigations.

## 🎯 Purpose

The purpose of these write-ups is to document my hands-on learning in
web application security and develop a practical understanding of
server-side vulnerabilities.

Each lab is approached as a practical security exercise, with emphasis on:

- Understanding the vulnerability
- Identifying the attack surface
- Analyzing HTTP requests and responses
- Reproducing the vulnerability
- Understanding the exploitation process
- Evaluating the potential security impact
- Understanding appropriate mitigation techniques
